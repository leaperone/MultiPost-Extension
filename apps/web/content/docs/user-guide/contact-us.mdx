## 如何提问
如果你在前台派发中遇到发布不了、内容没有显示、卡住、填写失败等问题，欢迎直接反馈。为了更快定位问题，请尽量提供环境、扩展版本、目标平台、复现步骤，以及截图或错误信息。也可以参考[《提问的智慧》](https://github.com/ryanhanwu/How-To-Ask-Questions-The-Smart-Way/blob/main/README-zh_CN.md)，让问题描述更清楚。

## 哪些问题可以联系我们
- 请求添加你常用的平台
- 汇报 Bug
- 提出改进建议
- 反馈前台派发中的发布流程问题，例如卡住、填写失败、自动发布不稳定
- 需要定制服务
- 对增值服务存在疑问
- ...
