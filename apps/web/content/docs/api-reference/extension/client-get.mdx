---
title: 获取单个客户端详情
description: GET /extension/client
---

> 需要 Bearer Token 鉴权。

## 端点

```http
GET https://api.multipost.app/extension/client
```

## 查询参数

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| clientId | string | ✓ | 客户端ID _e.g._ `cm97626yy000514gpzo6z9yuh` |

## 请求示例

```bash
curl -X GET 'https://api.multipost.app/extension/client' \
  -H "Authorization: Bearer YOUR_API_KEY"
```
