接受一个 MP3  格式的文件，返回语音识别结果。

> PS:
> 1. 请使用 https://stt.multipost.app 作为前置域名;
> 2. 仅支持 .mp3 文件

## 端点

```http
POST https://stt.multipost.app/
```

> **注意：** Speech To Text 使用独立域名 `https://stt.multipost.app`，仅支持 `.mp3` 文件。

## 请求体

`multipart/form-data`

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| file | string | ✓ |  |

## 请求示例

```bash
curl -X POST 'https://stt.multipost.app/'
```
