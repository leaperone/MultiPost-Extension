MultiPost 提供了一组 REST API，允许第三方应用调用扩展能力来发布内容、采集网页、获取社交媒体数据等。本节文档由 OpenAPI 规范生成并随仓库同步。

## 基础信息

- **生产环境地址：** `https://api.multipost.app`
- **Speech To Text 独立域名：** `https://stt.multipost.app`
- **鉴权方式：** 大多数端点要求在 HTTP 头中携带 Bearer Token，参见 [鉴权](./authentication)。
- **响应格式：** JSON；除特殊说明外均为 `application/json`。
