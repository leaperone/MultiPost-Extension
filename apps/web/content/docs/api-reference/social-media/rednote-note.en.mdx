---
title: RedNote · Get note
description: GET /v1/social/rednote/note
---

在获取小红书相关信息时，您可通过以下两种参数实现：
1. **note_id**：即笔记ID ，能从小红书分享链接里提取。
2. **share_text**：指小红书分享链接（涵盖APP端及Web端分享链接） 。
系统优先识别note_id参数。若该参数未提供，才会采用share_text参数。请您仅提供其中一个参数，若两个参数同时存在，系统将以note_id参数作为执行标准。

> Requires Bearer token authentication.

## Endpoint

```http
GET https://api.multipost.app/v1/social/rednote/note
```

## Query parameters

| Field | Type | Required | Description |
|---|---|---|---|
| note_id | string |  | Note ID _e.g._ `665f95200000000006005624` |
| share_text | string |  | 分享链接/Share link _e.g._ `https://xhslink.com/a/EZ4M9TwMA6c3` |

## Request example

```bash
curl -X GET 'https://api.multipost.app/v1/social/rednote/note' \
  -H "Authorization: Bearer YOUR_API_KEY"
```
