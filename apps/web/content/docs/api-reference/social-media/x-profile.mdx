---
title: X · 获取用户资料
description: GET /v1/social/x/profile
---

> 需要 Bearer Token 鉴权。

## 端点

```http
GET https://api.multipost.app/v1/social/x/profile
```

## 查询参数

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| rest_id | string |  | 用户ID（如果使用用户ID则会忽略用户名） _e.g._ `44196397` |
| screen_name | string |  | 用户名/Screen Name _e.g._ `elonmusk` |

## 请求示例

```bash
curl -X GET 'https://api.multipost.app/v1/social/x/profile' \
  -H "Authorization: Bearer YOUR_API_KEY"
```
