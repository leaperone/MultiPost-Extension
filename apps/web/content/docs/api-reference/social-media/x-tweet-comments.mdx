---
title: X · 获取推文评论
description: GET /v1/social/x/tweet/comments
---

> 需要 Bearer Token 鉴权。

## 端点

```http
GET https://api.multipost.app/v1/social/x/tweet/comments
```

## 查询参数

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| tweet_id | number |  | 例如：https://x.com/elonmusk/status/1908013951113195741 中的 1908013951113195741。 _e.g._ `1908013951113195800` |
| cursor | string |  |  |

## 请求示例

```bash
curl -X GET 'https://api.multipost.app/v1/social/x/tweet/comments' \
  -H "Authorization: Bearer YOUR_API_KEY"
```
