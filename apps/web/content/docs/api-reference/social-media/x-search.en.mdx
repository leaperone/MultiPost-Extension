---
title: X · Search
description: GET /v1/social/x/search
---

> Requires Bearer token authentication.

## Endpoint

```http
GET https://api.multipost.app/v1/social/x/search
```

## Query parameters

| Field | Type | Required | Description |
|---|---|---|---|
| keyword | string | ✓ | 关键词 _e.g._ `elonmusk` |
| search_type | enum(Top, Latest, Media, People, Lists) |  | 搜索类型，默认为「热门」 _e.g._ `Top` |
| cursor | string |  | 游标 |

## Request example

```bash
curl -X GET 'https://api.multipost.app/v1/social/x/search' \
  -H "Authorization: Bearer YOUR_API_KEY"
```
