---
title: X · 获取用户推文列表
description: GET /v1/social/x/tweets
---

从最新的开始

> 需要 Bearer Token 鉴权。

## 端点

```http
GET https://api.multipost.app/v1/social/x/tweets
```

## 查询参数

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| rest_id | string |  | 用户ID（如果使用用户ID则会忽略用户名） _e.g._ `44196397` |
| screen_name | string |  | 用户名/Screen Name _e.g._ `elonmusk` |
| cursor | string |  | 游标（用于翻页） |

## 请求示例

```bash
curl -X GET 'https://api.multipost.app/v1/social/x/tweets' \
  -H "Authorization: Bearer YOUR_API_KEY"
```
