---
title: X · 获取用户评论列表
description: GET /v1/social/x/replies
---

从最新的开始

> 需要 Bearer Token 鉴权。

## 端点

```http
GET https://api.multipost.app/v1/social/x/replies
```

## 查询参数

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| screen_name | string |  | 用户名/Screen Name _e.g._ `elonmusk` |
| cursor | string |  | 游标（用于翻页） |

## 请求示例

```bash
curl -X GET 'https://api.multipost.app/v1/social/x/replies' \
  -H "Authorization: Bearer YOUR_API_KEY"
```
