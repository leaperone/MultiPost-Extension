# 信用使用记录管理

## 概述

信用使用记录管理页面提供了简洁高效的信用使用情况监控功能，仿照 users 文件夹的结构设计。专注于数据展示，提供清晰的统计信息和详细的使用记录列表。

## 功能特性

### 1. 统计信息展示
- **总使用量**: 显示所有用户的信用总使用量
- **免费使用**: 显示免费信用的使用量
- **付费使用**: 显示付费信用的使用量  
- **活跃用户**: 显示使用过信用的用户总数

### 2. 信用使用记录表格
- **无限滚动**: 支持大量数据的无限滚动加载
- **用户信息**: 显示用户头像、姓名、邮箱
- **使用类型**: 不同类型的信用使用（图片生成、海报生成等）
- **金额显示**: 使用美元符号图标，精确到小数点后六位的金额显示
- **免费标识**: 清晰标识免费和付费使用
- **创建时间**: 本地化的时间显示

## 文件结构

```
app/admin/usage/

├── actions.ts                         # 服务端操作函数
└── components/
    ├── CreditUsageTable.tsx           # 信用使用记录表格组件
    └── CreditUsageStats.tsx           # 统计信息组件
```

## 技术实现

### 数据获取
- 使用 Prisma ORM 进行数据库操作
- 支持游标分页，提高大数据量查询性能
- 实现聚合查询获取统计信息

### 前端组件
- 基于 HeroUI 组件库构建
- 使用 React Stately 的 useAsyncList 管理异步数据
- 实现无限滚动加载优化用户体验

### 权限控制
- 仅管理员可访问
- 基于 NextAuth 的身份验证
- 服务端权限验证

## 使用方法

1. **访问页面**: 管理员登录后访问 `/admin/usage`
2. **查看统计**: 页面顶部显示关键统计信息
3. **浏览记录**: 滚动查看所有信用使用记录
4. **查看详情**: 表格显示用户信息、使用类型、金额等详细信息

## API 接口

### getCreditUsages
获取信用使用记录列表

**参数:**
- `cursor?: string` - 分页游标
- `limit?: number` - 每页数量，默认20

### getCreditUsageStats
获取信用使用统计信息

**返回:**
- `totalUsage: number` - 总使用量
- `freeUsage: number` - 免费使用量
- `paidUsage: number` - 付费使用量
- `uniqueUsers: number` - 活跃用户数

## 实现总结

本功能的实现完全仿照了 `app/admin/users` 文件夹的结构和设计模式：

### 架构设计
- **Server Actions**: 使用 `actions.ts` 文件处理所有服务端逻辑
- **组件化**: 将功能拆分为独立的 React 组件
- **类型安全**: 完整的 TypeScript 类型定义
- **权限控制**: 基于 NextAuth 的管理员权限验证

### 技术栈
- **前端**: React 19 + TypeScript + HeroUI + Tailwind CSS
- **后端**: Next.js App Router + Prisma ORM
- **数据库**: PostgreSQL with Decimal precision
- **状态管理**: React Stately (useAsyncList)
- **UI组件**: HeroUI Table + 无限滚动

### 核心特性
- **高性能**: 游标分页 + 无限滚动，支持大数据量
- **响应式**: 移动端友好的设计
- **实时统计**: 聚合查询提供准确的统计数据
- **类型安全**: 严格的 TypeScript 类型检查
