# @multipost/shared

Shared types and platform definitions used across MultiPost web, desktop, and extension.

## Usage

```ts
import { PLATFORMS, type PlatformType, type SyncContentType } from '@multipost/shared'
import { PLATFORMS, CONTENT_TYPE_LABELS } from '@multipost/shared/platforms'
import type { SyncData, FileData } from '@multipost/shared/types'
```

## Exports

- **types** - `PlatformType`, `PlatformInfo`, `SyncContentType`, `SyncData`, `FileData`, `DynamicData`, `VideoData`, `ArticleData`, `PodcastData`
- **platforms** - `PLATFORMS` (44+ platform definitions), `CONTENT_TYPE_LABELS`
